# ersh

Система для стратегии «ёрш» — сбора спреда об маркетмейкер-ботов на неликвидных
токенах криптобирж третьего эшелона. Разбор стратегии: [docs/strategy.md](docs/strategy.md).

Компоненты (пакет `ersh/`, только публичный API MEXC, ключи не нужны):

| Модуль | Запуск | Что делает |
|---|---|---|
| скринер | `python3 -m ersh.screener` | сканирует все спот-пары, ищет «ершистые» тикеры |
| вотчер | `python3 -m ersh.watch SYLUSDT --minutes 10` | live-наблюдение: диапазон ерша, клип, конкуренты, оценка $/час |
| симулятор | `python3 -m ersh.sim SYLUSDT --minutes 30` | paper-trading об живую ленту с реалистичным исполнением |
| оркестратор | `python3 -m ersh.run` | автообновляемый вотчлист + симуляторы + сигналы в Telegram |

## Скринер

1. **Фильтр вселенной** — все 24h-тикеры: пары к USDT, объём $500–$300k
   (живой, но неликвидный), спред ≥ 0.08%.
2. **Глубокий анализ** — лента сделок + стакан; сделки сворачиваются в «удары»
   (одна рыночная заявка бота). Метрики: `CLIP$` медианный удар (≈ ваш максимальный
   размер заявки), `CLIP3` повторяемость размера, `ALT` чередование сторон,
   `SPRD%`/`RNG%` спред и диапазон, `HIT/M` ударов в минуту.
3. **Скоринг** — повторяемость клипа 30%, чередование 20%, спред 20%,
   узость диапазона 15%, активность 15%. Отчёты в `reports/` (JSON + CSV).

## Вотчер

Следит за тикером в реальном времени: печатает каждый удар бота, границы ерша
(квантили цен ударов), частоту сторон, оценку дохода в час
(`пар/час × размер × захват спреда`) и **детекцию конкурентов** — долю времени,
когда чья-то заявка стоит внутри зоны ударов бота, то есть там, где встали бы мы
(такой же охотник за спредом уже занял очередь).

## Симулятор

Максимально консервативная модель исполнения об **реальную** ленту:

- наша лимитка исполняется, только если реальный принт прошёл *лучше* нашей цены,
  либо по нашей цене — после того как через уровень прошёл объём очереди,
  стоявшей перед нами на момент постановки, плюс наш объём;
- одна позиция за раз (как в видео): купить у нижней границы ерша → продать у верхней;
- размер заявки ≤ клипа бота (не ломаем его), минимум $1 (лимит MEXC);
- комиссии: мейкер 0% (MEXC спот), тейкер 0.05% — настраиваются;
- перестановка заявки каждые 45с, стоп по времени 45 мин с выходом тейкером по bid;
- не торгует, если захват спреда < 0.15%.

## Оркестратор + Telegram

`python3 -m ersh.run --config config.json` — постоянный процесс:

- раз в час (настраивается) прогоняет скринер и **автоматически обновляет вотчлист**
  с гистерезисом: добавляет тикеры со score ≥ 0.65, убирает при score < 0.50 или
  исчезновении; о каждом изменении пишет в группу;
- на каждый тикер вотчлиста — свой симулятор; 🟢 входы (с суммой), 🔴 выходы
  с PnL и временем в позиции, часовые сводки шлются в Telegram-группу;
- виртуальный баланс (старт `start_balance`, по умолчанию $100) обновляется
  после каждого выхода и печатается в уведомлении;
- состояние (вотчлист, баланс, PnL) переживает рестарт (`state/state.json`).

Настройка Telegram: создать бота у @BotFather, добавить его в группу,
скопировать `config.example.json` → `config.json` и вписать `telegram_token`
и `telegram_chat_id` (id группы можно узнать, переслав сообщение боту @getidsbot).
Без токена всё работает в консольном режиме.

Зависимости: Python 3.10+, `requests`.
