# ersh

Инструменты для стратегии «ёрш» — сбора спреда об маркетмейкер-ботов на неликвидных
токенах криптобирж третьего эшелона. Разбор стратегии: [docs/strategy.md](docs/strategy.md).

## Скринер MEXC

Сканирует все спот-пары MEXC и ищет «ершистые» тикеры — те, где котирует одинокий
ММ-бот. Только публичный API, ключи не нужны.

```bash
python3 screener/mexc_screener.py            # дефолтные фильтры
python3 screener/mexc_screener.py --top 40 --min-spread 0.2 --max-vol 100000
```

Как работает:

1. **Фильтр вселенной** — все 24h-тикеры: пары к USDT, объём в заданном коридоре
   (по умолчанию $500–$300k — живой, но неликвидный), спред ≥ `--min-spread`.
2. **Глубокий анализ** — для кандидатов тянет ленту сделок и стакан, сворачивает
   сделки в «удары» (одна рыночная заявка) и считает метрики:
   - `CLIP$` — медианный размер удара бота (≈ ваш максимальный размер заявки);
   - `CLIP3` — доля трёх самых частых размеров удара (повторяемость = бот);
   - `ALT` — частота чередования сторон (пинг-понг вверх/вниз);
   - `SPRD%` — текущий спред; `RNG%` — диапазон цены по последним сделкам;
   - `HIT/M` — ударов в минуту; `BOOK$` — стоимость топ-20 уровней стакана.
3. **Скоринг** — взвешенная сумма (повторяемость клипа 30%, чередование 20%,
   спред 20%, узость диапазона 15%, активность 15%). Отчёты пишутся в `reports/`
   (JSON + CSV).

Зависимости: Python 3.10+, `requests`.
